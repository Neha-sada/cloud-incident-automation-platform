# cloud-incident-automation-platform

A real-world cloud-native platform that simulates production incident detection,
alerting, and automated remediation using modern DevOps, Cloud, and QA practices.

## Tech Stack (Planned)
- Backend: Python (FastAPI)
- Frontend: Minimal Web UI
- Cloud: AWS (Free Tier)
- IaC: Terraform
- CI/CD: GitHub Actions
- Testing: Playwright (E2E), Pytest
- Monitoring: CloudWatch
